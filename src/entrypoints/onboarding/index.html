Docamatic

Sticky notes for the web.

Put a note on any page. It stays exactly where you left it, and you can find it again from anywhere: search everything you've written, tag notes, keep favorites.

Try it here

Add a practice note to this page. Drag it by its top edge, type in it, give it a tag. It disappears when you close this tab.

    Find it again

    Docamatic lists the notes on the page you're on, and searches all the others. Notes you made with earlier versions are all still here, in the same spots.
