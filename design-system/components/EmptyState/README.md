# EmptyState

What a view shows when it has nothing yet: one title, one sentence, and one action.

## Use

- `dm-empty`: a title in the display face, one short sentence saying what will appear here, and the primary action that makes it appear.
- Put a `dm-swipe` on one word of the title ("yet"), never more.
- No illustrations.
- Say what to do, not what's missing: "Jot down what you want to remember while you read", not "Nothing found".

## The consumer provides

The title, the sentence and the action.
