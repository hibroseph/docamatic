# Swipe

A highlighter stroke behind a word or two: Docamatic's signature mark, because the product is about marking things up.

## Use

- `<span class="dm-swipe">` around one to three words of a **title**: the onboarding headline, an empty state's title, a page title. Yellow by default; `--pink`, `--blue` and `--green` when yellow would clash with something next to it.
- At most **once per view**. It's the accent, not the texture.

## Don't

- Swipe body text, buttons or labels.
- Confuse it with a highlight (`dm-hl`), which marks what a person highlighted on a web page.
