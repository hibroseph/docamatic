Moving notes or starting fresh

  1. Click Download backup above.
  2. Uninstall and reinstall Docamatic (or install it on another computer).
  3. Open this page again: in the Docamatic popup, open Settings, then Backup & restore.
  4. Choose the file under Import a backup.
